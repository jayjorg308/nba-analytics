# Comparison state is owned by the URL

Every configured comparison has a stable URL that fully identifies its mode and inputs: shared season plus two players for player comparison, or player, season, and split date for within-season comparison. The comparison page uses no server-side saved state, so opening or sharing the URL reproduces the same comparison in the static deployment. A user-authored event note is descriptive context rather than authoritative comparison state and is not part of the canonical URL unless a later curated event model gives it stable identity.
