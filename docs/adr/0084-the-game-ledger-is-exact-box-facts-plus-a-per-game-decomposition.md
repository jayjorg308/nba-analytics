# The game ledger is exact box facts plus a per-game decomposition

The Jazz surface's **game ledger** lists the team's games in date order, one **game row** each. A game row is two things joined by game identity: the **box team line** (opponent, home or away, both scores, field goals made and attempted, free throws made and attempted, later the team's technical free throws), exported from the record store's observed box lines as `public/data/_teams/<tricode>/<season>.ledger.json`, and the **headline decomposition** for that game (league diet PPS, expected from diet, actual PPS, the selection delta and the making delta), computed in the browser by the unchanged aggregation over that game's slice of the team shot payload. The ledger's game set must equal the team shot payload's game set exactly; a game in one and not the other is a contradiction at the load boundary.

**Why the box line is exported and the decomposition is not.** The box line is an observation with no other source on the page; the decomposition is a derivation of rows the page already holds, and persisting derived metrics is what ADR-0007 forbids. Computing per game in TypeScript also keeps one implementation of the math (ADR-0009) and lets the season-to-date profile, the player profiles, and the game rows agree by construction, because they are the same function over nested slices.

**What a game row says and does not say.** At roughly 85 attempts a game clears the 50-attempt making bar overall, so the headline pair renders, always with its attempt count beside it and a plain thin-sample note when a game falls under the bar (short overtime-free blowouts and ejection-shortened games vary). **Zone grain per game is counts only**: attempts and makes per evaluation zone, with no vs-league shading and no per-zone delta, because no zone clears the 15-attempt bar in one game and a shaded 4-for-6 would be a graded reading of noise. A game row never compares itself to other games, shows no trend, and carries no note about why.

**Consequences.** The ledger facts file is small and exact; its export re-runs the game-set identity against the team shot payload. Team free-throw trips join the ledger only when a team trip derive reconciles every game's trips to the box team line under the ADR-0053 grammar. A future contributor must not persist per-game metrics, must not shade per-game zones, and must not add a running average or a streak to the ledger without a new decision.
