# Comparison windows use local sample flags

Comparison windows do not inherit hero eligibility. A comparison has no authored verdict, so a thin zone does not veto an otherwise useful exploratory profile: the page renders a non-empty window, keeps attempts visible, marks a zone below 15 attempts as too thin for a stable selection reading, and retains the existing making uncertainty flag below 50 attempts. Hero eligibility continues to protect complete published arguments; comparison honesty is carried locally by counts and flags.
