# Split-date comparisons use complete windows

A split-date comparison uses every available game in the season on both sides of the boundary: season start through the day before the split, and the split date through the reconciled frontier. The windows are not trimmed to equal game counts. Rates and shares remain comparable while visible game, shot, and per-zone attempt counts disclose unequal precision; matched-length sampling would discard relevant data and answer a different question.
