# Game photographs for the 2026-27 Jazz games through 2026-10-31

_2026-11-01. Where to find one photograph per game for the ADR-0094 report
card banner and share card, for the six 2026-27 games published through
2026-10-31. Gathered by reading the Jazz's and each opponent's team pages on
nba.com in a browser (the pages render client-side), reading each
candidate's pixel size from the CDN original as the browser loaded it,
viewing frames at reduced size to describe them, reading wire and newspaper
credits from the captions of pages that publish them (si.com, deseret.com,
sports.ksl.com), and reading licensing terms on each owner's own pages. No
image file was saved, no account was created, and nothing was signed into.
Reuters Connect's search sits behind a sign-in, so the Imagn coverage below
comes from published captions, not from the archive itself. **Inference**
marks a conclusion drawn from evidence rather than read off a source.
**Unverified** marks what could not be checked._

## How the Jazz CDN reads this season

These findings hold across all six games.

- **No game galleries.** The Jazz photos index lists no 2026-27 game
  gallery. Its newest entry is a community gallery about five months old,
  and the rest are "Best of 2025-26" player galleries
  ([nba.com/jazz/photos](https://www.nba.com/jazz/photos), read
  2026-11-01). This season the team's game photographs appear only as the
  single header image of its own recap and preview articles
  ([news index](https://www.nba.com/jazz/news)), with no caption and no
  credit on the page.
- **Three filename classes** under
  `cdn.nba.com/teams/uploads/sites/1610612762/2026/10/`:
  1. **Camera originals** (`DSC0xxxx`, `ZMR0xxxx`, `IMG_xxxx`). No credit
     on the page. `DSC01389.jpeg` carried no EXIF or XMP date or credit in
     its leading bytes as read in the browser. This is the class of the
     Ace, Cody, and Keyonte banners (`docs/image-credits.md`).
  2. **Team-photographer edits** named by date, matchup, and initials,
     such as `103126_UTA-vs-POR_ED_Edits-22.jpg`. A preseason sibling,
     `101226_UTA-vs.-SAS_ED_Edits_049.jpg`, is captioned "Emma Decasa/Utah
     Jazz" where it loads in the article stream beneath the
     [opener recap](https://www.nba.com/jazz/news/utah-jazz-fall-to-memphis-grizzlies-in-season-opener-key-takeaways),
     so "ED" is very likely Emma Decasa (inference).
  3. **The Getty tier, in two spellings.** One is `GettyImages-<id>.jpg`.
     The other is a **bare ten-digit Getty ID** (`2300585422.jpg`,
     `2300817274.jpg`, `2301566278.jpg`, `2301733701.jpg`,
     `2302573743.jpg`). Every bare-numeric file read this season is
     captioned "NBAE via Getty Images" or "Getty Images" with Getty's
     license notice. **The bare-numeric spelling is the new trap**: nothing
     in the filename says Getty. Every one is listed under its game below.
- **The upload folder is not the game date.** `docs/image-credits.md`
  already records this for the Lakers' CDN, and it holds here too. Each
  Jazz frame below is placed in a game by what it shows (Darryn Peterson,
  a 2026-27 rookie, wears 22; the venue; the jersey) and by where the Jazz
  published it. The jersey evidence:
  - **Purple on 10-25.** The NBAE frame `2301566278.jpg` is captioned for
    the Lakers game and shows George in purple (viewed;
    [Roundball Roundup](https://www.nba.com/jazz/news/roundball-roundup-ace-bailey-keyonte-george-lukas-52-and-west-tiers)).
  - **Purple on 10-26.** The lead Getty image of the
    [nba.com game page](https://www.nba.com/game/0022600126) shows George
    (3) and Bamba (44) in purple against Memphis in white (viewed).
  - **White on 10-28.** The NBAE frame `2302573743.jpg` is captioned for
    the Spurs game and shows Bailey in white (viewed;
    [Roundball Roundup](https://www.nba.com/jazz/news/roundball-roundup-young-players-stepping-up-road-trip-looming)).
  - **Black on 10-31**, in the frame whose filename names the game.
  - **White on 10-23** is not independently verified. Both Jazz frames
    placed with that game show white.
- **Venues agree.** The nba.com game pages match the published table:
  0022600089 is at FedExForum with the Jazz away
  ([page](https://www.nba.com/game/0022600089)), and the other five are at
  Delta Center with the Jazz at home
  ([0022600100](https://www.nba.com/game/0022600100),
  [0022600112](https://www.nba.com/game/0022600112),
  [0022600126](https://www.nba.com/game/0022600126),
  [0022600141](https://www.nba.com/game/0022600141),
  [0022600147](https://www.nba.com/game/0022600147)). One note, not a
  disagreement: the Spurs game went to overtime, so 111-117 is the

  ([Jazz recap](https://www.nba.com/jazz/news/utah-jazz-fall-short-in-overtime-against-san-antonio-spurs-key-takeaways),
  [AP via Deseret News](https://www.deseret.com/sports/2026/10/28/victor-wembanyama-scores-36-spurs-clamp-down-in-overtime-to-beat-the-jazz/)).
